## Artifact identity

Version **1.2.0** is **published** within the supported 1.x line. Its tagged artifact preserves the
historical pre-publication snapshot recorded during qualification. Publication does not change the
security reporting route or create a different support policy.

## Supported Versions

Currently, only the latest major version is actively supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Maatify Email Delivery, please send an email to the security team at **security@maatify.dev**.

All security vulnerabilities will be promptly addressed.

Please **do not** report security vulnerabilities through public GitHub issues.

When reporting, please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact and affected versions.
