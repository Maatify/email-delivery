# Maatify Email Delivery 1.3.0 — draft release notes

**Status: prepared candidate; unpublished.** These notes are not an announcement or proof of availability.
The latest published release remains [1.2.0](https://github.com/Maatify/email-delivery/releases/tag/v1.2.0).

## Overview

This planned additive minor release strengthens worker recovery and adds type-scoped queue processing,
while retaining the existing enqueue APIs and the PHP ^8.2 baseline. Release date and publication links
will be added only after an authorized release.

## Added and changed

- Worker connection factories allow a worker to replace server-closed connections. A configurable
  processing lease lets later batches reclaim interrupted jobs; delivery remains at-least-once.
- `processBatchByEntityType()` supports a worker dedicated to one exact entity type. Schema index 005
  improves general candidate reads; optional index 006 helps scoped batches behind other entity types.
- SMTP transport dependency compatibility expands to PHPMailer 7 while retaining PHPMailer 6.9 support.
- Worker connection checks reject non-exception PDO mode and disabled MySQL/MariaDB autocommit before
  claiming jobs.
- Recovery, concurrency, SMTP integration, static analysis and documentation checks receive additional
  coverage.

## Compatibility and adoption

The 1.3.0 candidate keeps the supported major line at 1.x. Review the [schema adoption guide](../upgrade.md)
before applying index 005 or optional index 006. Existing published 1.2.0 installations must update
every worker before relying on lease recovery or scoped batches. Do not run old and candidate workers
concurrently against the same queue during rollout.

This draft records the current candidate scope only. Final release content, date, version availability
and external verification remain pending owner authorization and exact-SHA qualification.
