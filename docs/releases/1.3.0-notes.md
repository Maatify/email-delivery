# Maatify Email Delivery 1.3.0 — release notes

**Qualification snapshot (recorded 2026-11-23):** at qualification, target 1.3.0 was **unpublished**. These notes are not an announcement or proof of current availability.
The latest published release **at qualification** was [1.2.0](https://github.com/Maatify/email-delivery/releases/tag/v1.2.0).

## Overview

This additive minor release strengthens worker recovery and adds type-scoped queue processing,
while retaining the existing enqueue APIs and the PHP ^8.2 baseline. This preparation record does not assert
an actual release date or publication link; see the live release record for current publication evidence.

## Added and changed

- Worker connection factories allow a worker to replace server-closed connections. A configurable
  processing lease lets later batches reclaim interrupted jobs; delivery remains at-least-once.
- `processBatchByEntityType()` supports a worker dedicated to one exact entity type. Schema index 005
  improves general candidate reads; optional index 006 helps scoped batches behind other entity types.
- SMTP transport dependency compatibility expands to PHPMailer 7 while retaining PHPMailer 6.9 support.
- Worker connection checks reject non-exception PDO mode and disabled MySQL/MariaDB autocommit before
  claiming jobs.
- Recovery, concurrency, SMTP integration, static analysis and documentation checks receive additional
  coverage.

## Compatibility and adoption

Version 1.3.0 keeps the supported major line at 1.x. Review the [schema adoption guide](../upgrade.md)
before applying index 005 or optional index 006. Existing published 1.2.0 installations must update
every worker before relying on lease recovery or scoped batches. Do not run 1.2.0 and 1.3.0 workers
concurrently against the same queue during rollout.

publication date, availability and publication evidence.
